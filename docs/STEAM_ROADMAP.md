# Star Steam 产品路线

## 产品定位

Star 是一款操作简单、强调无限反弹与主动引爆的无尽分数挑战游戏。

> 左键逐颗发射弹夹中的子弹，让它们无限反弹，再按空格原地引爆；命中敌人充满能量后，按 Q 释放一次近身冲击波。

玩家只需要理解四个动作：瞄准、发射、引爆和冲击波。游戏不加入移动、复杂技能栏、装备背包或元素克制。深度来自弹道安排、引爆时机和保命资源管理。

## 版本边界

Demo 用于验证核心循环是否能支撑 `15～30` 分钟的重复游玩。正式版只在 Demo 得到正向反馈后扩充内容，不推翻操作方式和星座成长结构。

| 内容 | Demo | 正式版 |
| --- | --- | --- |
| 模式 | 1 个无尽模式 | 无尽模式、每日固定种子挑战 |
| 场景 | 1 个纯色战斗场景 | 多套可解锁配色，布局不变 |
| 普通敌人 | 普通、装甲、分裂 | 增加加速、吸收、干扰，总数控制在 5～6 种 |
| Boss | 1 个完整 Boss | 3 个具有不同规则的 Boss |
| 成长 | 3 分支、9 节点 Demo 星座树 | 4 个星座、35～40 节点与星核构筑 |
| 操作 | 左键、空格、Q | 不增加新的战斗按键 |
| 长期内容 | 本地最高分、基础统计 | 排行榜、每日挑战、成就、外观解锁 |
| 语言 | 中文、英文 | 中文、英文 |

## Demo 版

### 验证目标

Demo 只回答一个问题：玩家是否愿意围绕“发射、反弹、引爆、冲击波”连续玩下去，并在失败后立刻再开一局。

需要验证：

- 新玩家能否在一分钟内理解发射与原地引爆。
- 玩家是否会等待子弹进入敌群再引爆。
- 玩家是否会保留弹药处理危险方向。
- 冲击波是否把近身危机变成可判断、可处理的错误。
- 前十分钟是否存在无聊期或无法处理的难度突变。
- 玩家能否用一句话复述游戏玩法。
- 一局结束后是否愿意立即重开。

### 核心战斗

- 玩家固定在战斗区域中心，敌人从四周直线接近。
- 初始弹夹为 `2` 发，每次点击只发射一颗，每颗可以重新瞄准。
- 子弹在墙壁和敌人之间无限反弹，命中敌人积累动量。
- 空格让所有子弹在各自位置产生独立爆炸，并立即装满弹夹。
- 命中普通敌人获得 `8%` 冲击波能量，命中 Boss 获得 `4%`，撞墙不充能。
- 能量达到 `100%` 后按住 Q 蓄力，松开时释放以玩家为中心的冲击波。
- 蓄力提高范围与伤害；普通敌人与 Boss 都按伤害减少生命，不会被无条件清除。
- 敌人接触玩家后立即死亡，死亡动画结束后进入星座技能树。

### Demo 敌人

Demo 只制作三种小怪，每种只表达一个行为：

1. **普通方块**：数量多，构成主要敌群。
2. **装甲方块**：生命较高，为连续反弹提供稳定目标。
3. **分裂方块**：死亡后产生较弱的小方块，制造适合引爆的密集区域。

敌人继续使用统一的纯色伪立体方块风格，通过尺寸、明度和移动规律区分。移动速度保持克制，后期压力主要来自数量、生命和组合。

### Demo Boss

Demo 只需要一个完整 Boss：

- 达到分数阈值后直接进入战场，不切换场景。
- Boss 周围持续出现普通敌人。
- 玩家利用小怪积累动量，再在 Boss 附近引爆。
- 冲击波可以伤害 Boss，但不能直接无条件清除 Boss。
- Boss 再次出现时提高生命、敌群密度和生成压力。

Boss 的目标是验证核心循环，不需要复杂技能树和多个阶段动画。

### Demo 星座技能树

战斗使用完整窗口，不再保留右侧商店。战斗中不会弹出升级卡片；分数达到固定
里程碑和击败 Boss 会自动获得星点，死亡后进入星座技能树。

Demo 初始提供 `3` 点。技能树包含三个分支，每个节点最多三级，并要求先点亮
同分支的上一个节点：

- **STARSHOT**：`IMPACT`、`AMMO`、`VELOCITY`。
- **NOVA**：`RADIUS`、`POWER`、`MOMENTUM`。
- **PULSE**：`CHARGE`、`RANGE`、`FORCE`。

星点和技能等级跨局保留，分数、时间与 Boss 进度在新一局重置。Demo 暂不设置
总点数上限，用来快速验证每条分支是否能产生清楚、可感知的成长。

### Demo 节奏目标

- `0～10` 秒：发射第一颗子弹。
- `30` 秒内：理解子弹会无限反弹。
- `60` 秒内：主动完成第一次引爆。
- `2～3` 分钟：获得第一个星点里程碑。
- `4～6` 分钟：遇到第一个 Boss。
- `10` 分钟后：敌群密度和画面反馈明显升级。
- `15～30` 分钟：形成完整一局，并出现明确的再玩动力。

这些时间是首轮调参目标，不是写死的游戏规则。试玩数据优先于设计预估。

### Demo 必备功能

- 四步动态提示：`AIM & FIRE`、`LET THEM BOUNCE`、`PRESS SPACE FOR NOVA`、`HOLD Q / RELEASE`。
- 最终分数、存活时间、击杀数、Boss 击杀数、最高单次引爆动量和最高单次引爆击杀数。
- 本地最高分与可靠存档。
- 暂停、重新开始和退出流程。
- 音量、全屏、分辨率和屏幕震动设置。
- 中英文切换。
- 基础手柄支持。
- 完整音乐循环与主要战斗音效。
- Windows 构建和 Steam Demo 页面所需素材。

### Demo 暂不开发

- 大量子弹类型和射击模式。
- 扇形、散射和自动攻击。
- 暴击、幸运、元素克制和随机词条。
- 装备、背包和品质系统。
- 剧情、每日任务和多人模式。
- 多张战斗地图。
- 在线排行榜和无限层数的数值成长。

## 正式版

正式版增加变化和长期目标，但不增加战斗按键。复杂度集中在战斗外的星座盘，
战斗中继续只保留瞄准、发射、引爆与冲击波。

### 正式版星座盘

正式版不通过简单增加数值节点扩充 Demo，而是把技能树扩展成能够形成流派的
星座盘：

- 总量控制在 `35～40` 个节点。
- 分为四个星座，每个星座约 `8～10` 个节点。
- 玩家一次只能投入约 `15～20` 点，不能点满全部能力。
- 节点沿星座连线解锁，随时允许免费洗点。
- 提供三套本地构筑预设，降低反复调整成本。
- 一次最多装备一个主星核；后期内容可解锁第二个星核槽位。

四个正式版星座：

1. **彗星**：高速弹射、连续撞击和动量成长。
2. **超新星**：主动引爆、范围覆盖和连环爆炸。
3. **引力**：聚怪、改变弹道和危险区域控制。
4. **脉冲**：冲击波充能、近身清场和容错。

节点分为三类：

- **属性节点**：提供少量、易理解的伤害、范围、速度和充能成长。
- **机制节点**：改变技能行为，例如引爆留下余波，或冲击波把敌人推向场边。
- **星核节点**：提供决定流派的强效果，同时附带明确代价。

计划中的星核示例：

- **白矮星**：降低子弹速度，提高直接命中和引爆伤害。
- **双生星**：增加弹夹容量，但降低每颗子弹的基础伤害。
- **黑洞核心**：引爆吸引附近敌人，但缩小基础爆炸范围。
- **脉冲星**：显著加快 Q 充能，但降低普通引爆伤害。
- **超临界**：满动量引爆产生第二次爆炸，同时清空冲击波能量。

正式版的成长流程为：

> 战斗 → 分数与 Boss 里程碑 → 获得星点 → 死亡结算 → 调整星座盘 → 再次挑战

Boss 奖励不会在战斗中弹出选择窗口。所有加点与星核调整都在结算后进行，以
保持无尽战斗的连续爽感。

### 敌人扩展

在 Demo 三种小怪通过验证后，最多增加三种：

- **加速方块**：接近中心后短暂提速，要求玩家提前处理。
- **吸收方块**：吸收附近小怪并变大，形成高价值引爆目标。
- **干扰方块**：被子弹击中时轻微改变反射角，打破完全固定的弹道。

每种敌人只拥有一个清晰行为。只有试玩证明现有组合无法支撑重复游玩时，才增加新品种。

### Boss 扩展

正式版准备三个 Boss：

1. **引力 Boss**：轻微改变附近子弹轨迹，考验引爆时机。
2. **分裂 Boss**：周期性制造敌群，为大范围引爆创造机会。
3. **屏障 Boss**：周围存在可击碎方块，玩家需要利用反弹寻找角度。

Boss 只改变一条核心规则，避免玩家同时处理多个复杂机制。

### 无限难度结构

游戏不显示传统关卡，也不弹出阶段结算卡片。一局持续循环：

> 稀疏敌群 → 密度上升 → 特殊敌人加入 → Boss → 短暂缓冲 → 更高强度循环

难度主要增加敌人数量、组合、生成角度、耐久和 Boss 频率。敌人移动速度设置上限，避免固定中心的玩家最终必然无解。

### 长期内容

- Steam 排行榜。
- 每日固定种子挑战。
- `10～15` 个成就。
- `5` 套以上可解锁纯色主题。
- 子弹、引爆和冲击波的外观变化。
- 历史数据统计。
- Steam Cloud。
- 完整手柄与 Steam Deck 适配。
- 色盲、震屏强度和闪光强度选项。

普通模式允许星座成长；排行榜与每日挑战使用独立的固定点数规则，确保分数竞争
不会由游玩时长决定。外观解锁不提供额外战斗数值。

## 视觉与原创性

Star 的视觉身份由固定纯色背景、白色伪立体方块和青白色爆炸构成。小星体保持纯净主体，不添加光环、射线或背景星点。

Steam 商店素材集中展示同一个核心瞬间：敌群包围玩家，子弹高速反弹，画面短暂停顿，多点爆炸同时展开，方块碎片和分数大量喷出。预告片开头直接展示玩法，不先播放 Logo 或说明文字。

上架前必须确认：

- 背景、UI、图标和动画为原创。
- 字体具有商业使用许可并按要求署名。
- 音效与音乐为原创或具有明确商用许可。
- 所有第三方素材在 `licenses/` 中记录来源和许可。

## 开发顺序

### Demo 阶段

1. 完成冲击波并调整充能、范围和反馈。
2. 完成普通、装甲、分裂三种敌人。
3. 完成第一个 Boss 和基于分数的重复出现逻辑。
4. 调整前十分钟的星点、技能树、敌人密度和生命成长。
5. 完成首次引导、结算统计和本地最高分。
6. 完成设置、存档、中英文和基础手柄支持。
7. 邀请至少 `10` 名不了解项目的玩家进行无讲解试玩。
8. 根据试玩数据调整核心循环，再制作 Steam Demo 页面和宣传素材。

### 正式版阶段

1. 根据 Demo 数据确认三条成长分支是否都能形成有效构筑。
2. 扩展为四星座盘，加入机制节点、星核、有限点数和免费洗点。
3. 增加两到三种经过验证的新敌人和两个 Boss。
4. 加入固定点数的排行榜模式、每日挑战、成就和历史统计。
5. 加入构筑预设、主题与外观解锁。
6. 完成 Steam Cloud、手柄、Steam Deck 和常见分辨率适配。
7. 优化大量敌人场景的性能和稳定性。
8. 制作正式版宣传素材并完成发布检查。

## 发布标准

Demo 达到以下条件后再公开发布：

- 新玩家一分钟内理解发射和引爆。
- 前十分钟不存在明显无聊期或无法处理的难度突变。
- 多点引爆成为玩家最期待的动作。
- 玩家知道冲击波何时可用，并愿意将它留到危险时刻。
- 死亡原因清楚，结算、加点和重开流程顺畅。
- 多数测试玩家愿意为了更高分再次开始。
- 游戏可以稳定保存、退出、重开并在常见分辨率下运行。

正式版进入内容扩充前，Demo 必须先证明核心循环成立。第一款游戏的成功标准首先是完整发布、获得真实玩家反馈，并建立下一款游戏可以复用的开发经验。
