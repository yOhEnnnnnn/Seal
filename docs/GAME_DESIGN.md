# Seal 当前玩法设计

## 核心循环

游戏开始后直接进入战斗。敌人持续生成，玩家固定在战斗区中心，使用鼠标瞄准并以无限弹药攻击。击杀敌人获得分数与金币，达到本轮目标后可继续战斗，也可按 `P` 进入下一轮。三轮目标分依次为 `24 / 50 / 90`。

连续击杀会把倍率从 `×1.0` 提高到最高 `×3.0`。达标后继续停留会逐渐提高生成压力与金币收益；此时死亡只丢失达标后获得的金币。生命归零时本局失败。

## 画面布局

内部画布为 `480 × 270`：

- 左侧战斗区为 `330 × 270`，占总宽度 `68.75%`。
- 右侧信息面板为 `150 × 270`，占总宽度 `31.25%`。
- 比例与参考图一致，分割线固定在 `x = 330`。
- 玩家、敌人、子弹和准星只存在于左侧战斗区。
- 右侧使用浅色矩形商店，左上显示金币，右上显示 `BOSS 当前分/目标分`，中间纵向排列商品。

商店与战斗同时存在，没有独立商店阶段。商品包括金币收益、暴击率、幸运、子弹伤害、反弹次数、射速和自动攻击。升级立即生效并跨轮保留；达标后按 `P` 直接切换到下一轮，圆形淡色遮罩从战斗区中心展开。

## 战斗与计分

Demo 使用无限的白色普通子弹。金币收益每级增加 `15%`；暴击率每级增加 `5%`，暴击造成双倍伤害；幸运每级增加 `3%`，命中时随机触发烬火区域、霜痕区域或闪电链。伤害、反弹和射速也通过商店升级；解锁自动攻击后，玩家会持续瞄准距离最近的存活敌人，不再依赖鼠标位置。

本次击杀分为怪物基础分加子弹加分值，再乘当前连击倍率并四舍五入。子弹初始加分值为 1，每次碰墙反弹增加 1。击杀金币以怪物基础分为基准，不受子弹加分影响。

## 表现与操作

- 敌人为 `16 × 16` 白色方块，始终用一条边正对玩家并沿该方向缓慢直线移动，不会自转或摆动。方块下方带固定右下偏移的灰色厚度层，形成简洁的伪立体效果；无描边和血条，剩余生命越低，主体与厚度层的透明度越低。
- 玩家和敌人统一经过轮廓阴影 Shader；子弹绘制为沿飞行方向旋转的短矩形，并带固定右下偏移的灰色厚度层，形成伪立体弹块。
- 鼠标进入左侧战斗区时隐藏系统指针并显示四角准星；进入右侧商店时恢复系统指针。
- 飞行子弹带有 `±3°` 随机散布。
- `鼠标左键`：在左侧攻击，在右侧购买商品。
- `P`：达标后进入下一轮或完成本局。
- `R`：失败或通关后重新开始。
- `Esc`：退出游戏。

## 文件职责

- `game.lua`：本局状态、分数、金币、关卡切换和画布合成。
- `arena.lua`：左侧战斗区的对象组、生成、更新、绘制和输入。
- `sidebar.lua`：右侧信息面板与标签栏。
- `hud.lua`：战斗区生命、连击、危险等级和提示。
- `player.lua`：玩家攻击和视觉表现。
- `enemy.lua`：敌人移动、碰撞、受伤和绘制。
- `projectile.lua`：飞行、连续碰撞、反弹和命中处理。
- `effect.lua`：命中粒子、幸运特殊效果和场景过渡。
- `data/bullets.lua`：普通子弹颜色与击杀加分配置。
- `data/enemies.lua`：敌人速度、尺寸、生命、伤害、生成频率和数量上限。
- `data/levels.lua`：各轮目标与生成参数。

游戏类由 `main.lua` 按依赖顺序加载；配置由 `data.lua` 统一汇总。

## 验证

在项目根目录运行 `lua tests/run.lua`。测试覆盖碰撞、无限弹药、商店升级、计分、关卡切换、左右区域输入边界和场景绘制。
