# Seal 当前玩法设计

## 核心循环

游戏开始后直接进入无尽战斗。敌人从四周持续生成，玩家固定在战斗区中心，使用鼠标瞄准并以无限弹药攻击。击杀敌人持续累积分数与金币，没有目标分、关卡切换或通关状态。

游戏每经过 `30` 秒提升一级威胁，之后生成的怪物会变得更耐打、更快、接触伤害更高，同时生成间隔逐渐缩短。玩家生命归零时本局结束，按 `R` 从零开始新的一局。

## 画面布局

内部画布为 `480 × 270`：

- 左侧战斗区为 `330 × 270`，占总宽度 `68.75%`。
- 右侧信息面板为 `150 × 270`，占总宽度 `31.25%`。
- 比例与参考图一致，分割线固定在 `x = 330`。
- 玩家、敌人、子弹和准星只存在于左侧战斗区。
- 右侧使用浅色矩形商店，左上显示金币，右上显示累计分数，中间纵向排列商品。

商店与战斗同时存在，没有独立商店阶段。商品包括金币收益、暴击率、幸运、击打强度、反弹次数、射速和自动攻击。升级购买后立即生效，并持续到本局结束。

## 战斗与计分

Demo 使用无限的白色普通子弹。敌人没有生命值，只有“最多承受击打次数”和“剩余击打次数”；开局普通怪需要命中 `3` 次，普通子弹默认消耗 `1` 次，剩余次数归零时死亡。金币收益每级增加 `15%`；暴击率每级增加 `5%`，暴击拥有双倍击打强度；幸运每级增加 `3%`，命中时随机触发烬火区域、霜痕区域或闪电链。击打强度、反弹和射速也通过商店升级；解锁自动攻击后，玩家会持续瞄准距离最近的存活敌人，不再依赖鼠标位置。

怪物按时间成长：每 `30` 秒提升一级威胁，每两级威胁增加 `1` 次承受击打，每级威胁增加 `4%` 移动速度和 `1` 点接触伤害。移动速度额外加成最高为 `40%`，刷怪间隔最低为 `0.08` 秒，以保持画面可读性；击打次数和接触伤害没有时间上限，因此战斗压力会持续增长。成长只作用于之后生成的怪物，场上已有怪物不会中途变化。

本次击杀分为怪物基础分加子弹加分值，连续击杀不产生额外倍率。子弹初始加分值为 1，每次碰墙反弹增加 1。击杀金币以怪物基础分为基准，不受子弹加分影响。

## 表现与操作

- 敌人为 `16 × 16` 白色方块，始终用一条边正对玩家并沿该方向缓慢直线移动，不会自转或摆动。方块下方带固定右下偏移的灰色厚度层，形成简洁的伪立体效果；无描边和血条，剩余击打次数越少，主体与厚度层的透明度越低。
- 玩家和敌人统一经过轮廓阴影 Shader；子弹绘制为沿飞行方向旋转的短矩形，并带固定右下偏移的灰色厚度层，形成伪立体弹块。
- 鼠标进入左侧战斗区时隐藏系统指针并显示四角准星；进入右侧商店时恢复系统指针。
- 飞行子弹带有 `±3°` 随机散布。
- `鼠标左键`：在左侧攻击，在右侧购买商品。
- `R`：失败后重新开始。
- `Esc`：退出游戏。

## 文件职责

- `game.lua`：本局状态、时间、难度、分数、金币和画布合成。
- `arena.lua`：左侧战斗区的对象组、生成、更新、绘制和输入。
- `sidebar.lua`：右侧信息面板与标签栏。
- `hud.lua`：战斗区生命、存活时间和威胁等级。
- `player.lua`：玩家攻击和视觉表现。
- `enemy.lua`：敌人移动、碰撞、受伤和绘制。
- `projectile.lua`：飞行、连续碰撞、反弹和命中处理。
- `effect.lua`：命中粒子和幸运特殊效果。
- `data/bullets.lua`：普通子弹颜色与击杀加分配置。
- `data/enemies.lua`：敌人速度、尺寸、承受击打次数、接触伤害、时间成长、生成频率和数量上限。

游戏类由 `main.lua` 按依赖顺序加载；配置由 `data.lua` 统一汇总。

## 验证

在项目根目录运行 `lua tests/run.lua`。测试覆盖碰撞、无限弹药、商店升级、计分、时间成长、刷怪下限、左右区域输入边界和场景绘制。
