# Seal 玩法设计

## 设计目标

制作一款操作简单、界面克制、适合轻松游玩，但能够持续产生爆发爽感的无尽游戏。

玩家只需要瞄准和点击，不承担移动、换弹或复杂技能管理。深度来自一次齐射内部的判断：让子弹继续反弹积累动量，还是立即将它们聚焦引爆。

## 核心循环

1. 玩家瞄准一个方向，发射当前拥有的全部子弹。
2. 子弹命中敌人后反弹，并不断积累动量。
3. 本轮子弹仍在场时，玩家不能开始下一轮齐射。
4. 玩家可以再次点击，将所有存活子弹聚焦到指定位置。
5. 聚焦根据累计动量产生范围伤害和分数奖励。
6. 子弹自然消失或聚焦完成后，下一轮齐射重新就绪。

核心体验可以概括为：

> 发射 → 反弹积累 → 观察敌群 → 选择时机 → 聚焦爆发

## 操作原则

- 鼠标移动：瞄准。
- 第一次点击：朝准星方向平行发射全部子弹。
- 子弹飞行期间再次点击：在鼠标位置聚焦全部子弹。
- 玩家固定在战斗区域中心，不需要移动。
- 敌人接触玩家后立即死亡。
- 死亡后可以花费金币复活，保留本局构筑和进度。

操作数量保持不变，通过时机、目标位置和当前弹道形成决策。

多颗子弹在玩家周围横向排列，以相同方向平行飞行。队列宽度固定，
子弹增加时自动缩小彼此间距。游戏不提供扇形角度、散射范围或其他
射击模式，避免玩家把注意力从反弹和聚焦上移开。

## 聚焦系统

聚焦是游戏的主要主动能力，也是后续所有内容的设计中心。

- 场上子弹的总动量决定聚焦范围。
- 总动量提高聚焦伤害和额外得分。
- 聚焦位置由玩家决定，可以用来收割密集敌群或攻击 Boss。
- 子弹自然消失不会产生聚焦爆炸。

### 完美聚焦

下一阶段优先实现“完美聚焦”。子弹进入寿命最后约 `25%` 时开始明显
闪烁；玩家在闪烁期间发动聚焦，就触发极短停帧和金白色爆发，并获得
额外范围、伤害和分数。聚焦未击杀敌人时只损失本轮积累，不追加惩罚。

完美聚焦只保留一个判断条件。玩家通过画面提示就能理解时机，无需记忆
命中次数或其他隐藏规则。

## 商店设计

商店固定为五项，只强化“发射、反弹、聚焦”这条核心链路：

- `BALL`：每轮多发射一颗子弹。
- `POWER`：提高单次命中伤害。
- `SPEED`：提高子弹飞行速度。
- `MOMENTUM`：提高反弹获得的动量。
- `FOCUS`：提高聚焦范围。

不加入扇形角度、暴击、幸运、被动金币倍率、额外射击模式或复杂连锁
升级。每项商品都应当能用一句话解释，并立即改变核心循环的手感或收益。

## 敌人设计

敌人的职责不是提供大量技能，而是形成适合反弹和聚焦的目标结构。
首个完整版本只保留普通方块、分裂方块和 Boss。

### 普通方块

- 数量多，构成主要敌群。
- 从战斗区边缘直线接近玩家。
- 用于制造连续反弹和大范围收割。

### 分裂方块

- 死亡后生成多个较弱的小方块。
- 延长一轮齐射并提高聚焦击杀数量。

### Boss 方块

- 达到分数阈值后直接进入战场，不切换场景。
- 持续在周围生成小怪。
- 玩家利用小怪积累动量，再聚焦攻击 Boss。
- Boss 被击败后进入更高强度阶段。

所有敌人继续使用统一的纯色伪立体方块风格，通过尺寸、亮度和运动规律
表达差异。只有现有三类敌人无法支撑长期体验时，才考虑增加新品种。

## 无限成长节奏

游戏不设置传统关卡，也不在阶段之间弹出结算卡片。一次游戏持续循环：

> 铺场期 → 反弹积累期 → 高密度期 → Boss 出现 → 大量结算 → 下一阶段

- 分数决定 Boss 出现时机。
- Boss 死亡后提高生成密度和怪物强度。
- 背景色、音效层次和粒子强度可以随阶段渐变。
- 所有变化在当前场景内完成，不打断玩家操作。
- 小怪成长以数量和组合压力为主，避免单纯堆叠生命值。

## 死亡与复活

- 敌人碰到玩家后触发短暂停帧、白闪和玩家碎裂。
- 场上敌人先向中心收束，再被死亡冲击波逐圈推出。
- 死亡界面出现后，玩家可以支付金币复活。
- 复活时玩家从中心重新组合，释放清场波，附近敌人被移除。
- 被死亡波推出的怪物平滑回到真实位置，动画结束后恢复控制。
- 复活保留分数、时间和升级，价格随复活次数增长。
- 金币不足时，本局才真正结束。

死亡和复活是一段连续演出：死亡负责炸开，复活负责重组。

## 视觉与反馈原则

- 战斗画面保持深色背景、白色伪立体敌人和少量强调色。
- 普通反馈使用白色，聚焦使用青色，完美聚焦使用金白色。
- 重要动作通过停帧、缩放、镜头震动、粒子和音效共同表达。
- 普通命中反馈保持轻量，聚焦、Boss 击杀和死亡使用强反馈。
- UI 不遮挡战斗，不通过频繁弹窗打断节奏。

## 开发顺序

1. 实现完美聚焦判定、反馈和奖励。
2. 调整子弹寿命、动量成长与聚焦收益，确定一轮齐射的理想节奏。
3. 完成平行齐射，并调整多颗子弹的横向排列。
4. 完善分裂方块和第一种 Boss，建立基于分数的阶段循环。
5. 根据实际游玩数据整理五项商品的价格和成长曲线。
6. 最后补充音乐层次、阶段配色和长期记录。

## 当前文件职责

- `game.lua`：游戏状态、分数、金币、难度、死亡和复活流程。
- `arena.lua`：对象管理、敌人生成、齐射、聚焦与场景动画。
- `player.lua`：玩家表现、平行齐射和升级属性。
- `projectile.lua`：子弹飞行、命中反弹、动量和生命周期。
- `enemy.lua`：敌人移动、承伤、碰撞和伪立体绘制。
- `effect.lua`：命中、聚焦、死亡和复活特效。
- `hud.lua`：战斗信息、聚焦状态和复活界面。
- `sidebar.lua`：常驻商店面板和购买交互。
- `data/`：玩家、敌人、升级、音效和规则配置。
- `tests/run.lua`：核心玩法和状态转换测试。
