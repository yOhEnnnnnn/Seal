# 圆形与方框特效实现归档

本文档保存两种已删除的区域表现。这里只记录视觉实现；伤害、状态和目标规则应由未来拥有该特效的角色自行提供。

## 分段圆形区域

### 参数

- 半径：由角色传入；旧原型使用过 `48` 和 `64`。
- 填充透明度：`0.06`。
- 淡入时间：`0.05` 秒。
- 淡出时间：`0.10` 秒。
- 外框：每隔 `pi / 2` 放置一段开放圆弧，共四段。
- 单段圆弧跨度：`pi / 5`。
- 线宽：`2` 像素。
- 初始旋转：`0` 到 `2 * pi` 之间随机。
- 旋转速度：每秒 `-pi / 4` 到 `pi / 4` 之间随机。
- 出现动画：使用 cubic in/out，在 `0.05` 秒内从 `0` 放大到 `1`，完成后用
  `0.15 / 200 / 10` 参数拉动一次弹簧。

### 更新与绘制

```text
时间 += dt，并限制在持续时间内
旋转 += 旋转速度 * dt
更新出现缩放和弹簧
透明度 = min(淡入进度, 淡出进度)

将坐标原点移动到区域中心
按 出现缩放 * 弹簧值 进行缩放
绘制一个低透明度实心圆
遍历四个象限：
  根据当前旋转绘制一段短圆弧
恢复绘制状态
```

圆形区域的敌人判定：

```text
(敌人.x - 区域.x)^2 + (敌人.y - 区域.y)^2 <= 半径^2
```

## 闪烁方框

### 参数

- 默认目标尺寸：`28` 逻辑像素。
- 初始旋转：`0` 到 `pi` 之间随机。
- 填充透明度：`0.08`。
- 放大时间：`0.08` 秒，使用 cubic in/out。
- 开场白色闪光：`0.12` 秒。
- 闪烁间隔：`0.06` 秒。
- 闪烁次数：`4`。
- 默认总持续时间：`0.36` 秒。

### 形状

- 绘制一个低透明度实心方块。
- 不绘制完整边框，只绘制每个角的两条短线。
- 每条角线长度为当前方框尺寸的 `16%`。
- 方框尺寸从 `64` 到 `160` 时，线宽从 `2` 映射到 `3`，超出范围时夹紧。
- 开场使用白色边框，之后切换为角色颜色，并按闪烁间隔交替显示和隐藏。

### 更新与绘制

```text
时间 += dt，并限制在持续时间内
尺寸 = 目标尺寸 * cubic_in_out(min(时间 / 0.08, 1))

如果时间 >= 0.12，且 floor((时间 - 0.12) / 0.06) 为奇数：
  本帧不绘制

开场闪光期间边框为白色，否则为角色颜色
在保存的旋转角度下绘制淡填充和八条角线
```
