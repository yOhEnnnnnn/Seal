# Arc / 电弧实现归档

本文档保存已删除的 Arc 原型，之后重新设计角色时，可以复用它的传导逻辑和电弧表现。

## 定位

- 名称：`Arc`
- 颜色：蓝色（`1, 155, 214`）
- 用途：清理站位接近、能够互相传导的敌群。
- 自动瞄准范围：`160` 逻辑像素。

## 等级规则

### 一级

- 攻击间隔：`1.0` 秒。
- 第一个目标使用玩家的通用自动瞄准规则选择。
- 第一个目标受到 `10` 点伤害。
- 随后最多额外传导 `2` 次。
- 每次选择上一个目标 `64` 范围内最近且尚未命中的敌人。
- 后续目标受到 `5` 点伤害。
- 同一次放电不会重复命中同一个敌人。

### 二级

- 传导方式、范围和次数不变。
- 所有伤害乘以 `1.2`。
- 首个目标伤害变为 `12`，后续目标伤害变为 `6`。
- 旧版共享生命规则会增加 `5` 点最大生命和当前生命。

### 三级

- 攻击间隔：`2.0` 秒。
- 玩家 `88` 范围内的所有敌人都成为初始分支。
- 每个初始目标受到 `12` 点伤害。
- 每条分支最多继续传导 `4` 轮。
- 每一轮从当前分支终点 `128` 范围内，随机选择一个尚未命中的敌人。
- 后续目标受到 `2.4` 点伤害。
- 所有分支共用一个命中集合，因此同一次放电不会重复伤害同一敌人。

## 传导算法

```text
一级和二级：
  已命中 = {初始目标}
  伤害初始目标
  起点 = 初始目标
  最多重复 2 次：
    目标 = 起点 64 范围内最近的未命中敌人
    没有目标则停止
    伤害目标并加入已命中集合
    起点 = 目标

三级：
  根目标 = 玩家 88 范围内的所有敌人
  已命中 = 所有根目标
  伤害所有根目标并绘制玩家到根目标的电弧
  分支 = 根目标
  重复 4 轮：
    遍历每条分支：
      目标 = 分支终点 128 范围内随机的未命中敌人
      如果存在目标，则造成伤害、绘制电弧并把分支推进到该目标
```

## 电弧表现

- 初始是一条连接起点和终点的直线段。
- 执行 `3` 轮中点位移。
- 第一轮的垂直随机偏移最大为 `8` 像素，之后每轮减半。
- 将生成的点绘制成一条折线。
- 线宽在 `0.1` 秒内从 `3` 缩小到 `1`。
- 电弧存在时，在起点和终点各绘制一个半径为 `6` 的前景色圆点。
- 起点生成两个受击粒子，终点生成一个受击粒子。
- 折线结束后，等待粒子全部结束再销毁整个特效。

折线生成算法移植自 SNKRX 的 `LightningLine`。以后重新使用时，必须继续保留
`licenses/SNKRX-LICENSE.txt` 中的署名和许可证。
