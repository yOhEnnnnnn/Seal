# Star 摄像机反馈设计

## 目标

复刻 SNKRX 的反馈结构，而不是让每次命中都震动。

反馈分为三层：

1. 普通攻击使用有方向的弹簧位移。
2. 普通命中主要依靠敌人闪白、缩放和粒子，不触发全屏震动。
3. 玩家受伤、爆炸和大型事件才使用随机震屏。

这样既有冲击力，也能保持画面干净。

## SNKRX 的实现方式

参考文件：

- `SNKRX-master/engine/graphics/camera.lua`
- `SNKRX-master/engine/math/spring.lua`
- `SNKRX-master/engine/game/hitfx.lua`
- `SNKRX-master/player.lua`
- `SNKRX-master/arena.lua`

### 随机震屏

接口：

```lua
camera:shake(intensity, duration, frequency)
```

行为：

- X 和 Y 分别生成一组随机采样。
- 默认采样频率为 60。
- 相邻采样之间进行线性插值。
- 振幅在持续时间内线性衰减到 0。
- 多个震动可以同时存在，最终位移相加。
- 每帧先减去上一帧震动，再加上当前震动，避免镜头产生永久漂移。

SNKRX 常用参数：

| 场景 | 参数 |
| --- | --- |
| 中型冲击 | `shake(2, 0.5)` |
| 玩家受伤 | `shake(4, 0.5)` |
| 精英或波次出现 | `shake(4, 0.25)` |
| 大型技能 | `shake(5, 0.25)` |
| 极强爆发 | `shake(6, 1)` |

### 方向弹簧

接口：

```lua
camera:spring_shake(intensity, angle, stiffness, damping)
```

行为：

- 根据攻击角度拆分为 X、Y 位移。
- 镜头先向攻击反方向后坐，再由弹簧回到中心。
- SNKRX 普通射击通常使用 `spring_shake(2, angle)`。
- 默认弹簧参数约为刚度 `100`、阻尼 `10`。

方向弹簧比随机震屏更适合高频射击，因为反馈明确且不会让画面持续抖动。

### 画面变换顺序

世界层绘制时按以下顺序变换：

1. 移动到屏幕中心。
2. 应用镜头缩放。
3. 应用镜头旋转。
4. 移动到镜头的世界坐标。

UI 层不应用摄像机变换，因此金币、分数、子弹背包和商店始终稳定。

## Star 的实现规格

### 文件结构

```text
engine/graphics/camera.lua   摄像机、随机震屏和方向弹簧
game.lua / arena.lua        更新摄像机并划分世界层与 UI 层
projectile.lua              在合适的子弹事件中请求反馈
enemy.lua                   继续负责受击闪白、形变和粒子
```

Camera 最小接口：

```lua
Camera(x, y)
Camera:update(dt)
Camera:attach()
Camera:detach()
Camera:shake(intensity, duration, frequency)
Camera:spring_shake(intensity, angle, stiffness, damping)
Camera:to_world(x, y)
```

### 更新规则

- Camera 使用未经减速的真实 `dt` 更新。
- 游戏对象以后即使加入慢动作，镜头也必须正常完成回弹。
- 镜头基础位置固定为 `gw / 2, gh / 2`。
- Star 的玩家目前固定在中心，因此暂时不实现跟随、死区和移动预判。
- 每帧合并随机震动与方向弹簧，得到最终偏移。

### 绘制分层

```text
Canvas
├── 静态底色
├── Camera 世界层
│   ├── 背景图形
│   ├── 瞄准虚线
│   ├── 子弹
│   ├── 敌人
│   ├── 玩家
│   └── 战斗特效
└── 固定 UI 层
    ├── GOLD
    ├── SCORE
    ├── 子弹背包
    ├── 商店
    └── 鼠标小点
```

背景图形需要比可视区域向外多绘制至少 12 像素，避免震屏时露出黑边。

鼠标位置需要经过 `Camera:to_world()` 转换后再用于瞄准。鼠标小点仍按屏幕坐标绘制，不跟随镜头震动。

## 事件参数

### 普通开火

```lua
camera:spring_shake(2, bullet_angle)
```

- 每次成功消耗子弹并生成 Projectile 后触发。
- 冷却中、没有子弹或未成功发射时不触发。
- 后坐方向与子弹方向相反。

### 普通命中

不调用 Camera。

保留当前反馈：

- 敌人短暂闪白。
- 敌人受击弹簧缩放。
- 命中圆环。
- 三枚左右的受击粒子。

这是 SNKRX 保持高频战斗清晰的关键。若每颗子弹命中都震屏，连续射击会变成持续噪声。

### 子弹撞墙

普通子弹撞墙不震屏，只显示墙面粒子。

反弹子弹成功反弹时既不震屏，也不显示墙面粒子；最后一次无法继续反弹并消失时才显示粒子。

### 闪电链

- 首次发射使用一次 `spring_shake(2, angle)`。
- 每次传导只显示电弧端点粒子与目标闪白。
- 不为每个传导目标重复震屏。

### 玩家受伤

```lua
camera:shake(4, 0.5)
```

同时触发玩家闪白与缩放反馈。连续受伤时允许震动叠加，但总位移限制在 8 像素以内。

### 中型爆炸

```lua
camera:shake(2, 0.5)
```

适用于范围攻击、敌人分裂或中等规模爆炸。

### 大型爆炸

```lua
camera:shake(4, 0.5)
```

适用于覆盖较大区域、清除一组敌人的效果。

### 极强事件

```lua
camera:shake(6, 1)
```

只用于极少出现的终局爆发、Boss 死亡或整屏级效果，不能作为普通技能反馈。

### 波次开始

```lua
camera:shake(4, 0.25)
```

短而明显，用于提示新波次或高威胁敌人出现。

## 强度限制

- 同时叠加后的 X、Y 位移分别限制在 `-8` 到 `8` 像素。
- 普通开火只使用方向弹簧，不叠加随机震屏。
- 同一帧多个敌人死亡只触发一次对应的爆炸震动。
- 商店状态停止并清空所有摄像机反馈。
- 切换到下一关前将镜头位置、旋转、缩放和弹簧恢复默认值。
- 默认不使用镜头缩放脉冲，避免像廉价的屏幕弹跳。

## 可选慢动作

SNKRX 还会将世界更新乘以 `slow_amount`，再缓动回 `1`。这不是摄像机本身，但可以与大型反馈组合。

Star 第一版只预留接口，不用于普通命中：

```lua
game:slow(0.25, 0.08)
```

只建议用于 Boss 死亡或极强爆发。Camera 与 UI 仍使用真实 `dt`。

## 实施顺序

1. 实现 Camera、随机噪声震屏和双轴 Spring。
2. 在 `Game` 中划分世界层与固定 UI 层。
3. 接入鼠标世界坐标转换。
4. 为普通开火接入方向弹簧。
5. 为玩家受伤、爆炸和波次事件接入随机震屏。
6. 最后根据实际手感调整参数，不先加入慢动作或缩放脉冲。

## 验收标准

- 连续快速射击时能感到后坐，但准星和 HUD 不抖。
- 普通命中清晰，不会每次都推动整个画面。
- 玩家受伤与大型爆炸明显强于普通射击。
- 闪电链命中多个敌人时只产生一次镜头反馈。
- 多次震动叠加后镜头不会漂离中心。
- 震动结束后位置、旋转和缩放完全恢复。
- 商店页面保持静止，没有战斗遗留震动。
- 震屏期间背景不会出现黑边。
