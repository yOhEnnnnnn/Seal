# 游戏数据配置

统一入口为根目录 `data.lua`，游戏启动后通过 `Data` 访问。修改配置后重启游戏生效。

| 文件 | 配置内容 |
| --- | --- |
| `audio.lua` | 合成音效的音高、时长、音量与并发声部 |
| `player.lua` | 玩家生命、大小、弹夹容量、弹速、击打强度、爆炸、冲击波与震屏 |
| `bullets.lua` | 普通子弹颜色、击杀加分和反弹加分 |
| `enemies.lua` | 敌人属性、时间难度成长、刷怪、强化、分裂与剩余击打次数透明度 |
| `upgrades.lua` | 星座分支、节点上限与升级增量 |
| `rules.lua` | 初始星点、星点里程碑与死亡流程参数 |
| `theme.lua` | 游戏配色 |
| `display.lua` | 逻辑尺寸、战场尺寸、窗口尺寸与字体 |

例如：调整基础击打强度修改 `player.lua` 的 `projectile_hit_power`；调整击打强度升级幅度修改 `upgrades.lua` 的 `hit_power_per_level`；调整难度提升周期修改 `enemies.lua` 的 `difficulty_seconds`。

配置表视为只读，生命、星点和升级等级等运行状态保存在各实例中。游戏通过鼠标左键从弹夹中手动发射一颗普通子弹，每颗都可以重新瞄准；子弹在敌人与墙壁之间无限反弹，玩家按空格主动引爆场上所有子弹并装满弹夹。命中敌人会为 `Q` 键冲击波增加百分比能量，撞墙不充能；能量满后按住 Q 蓄力，松开释放并根据蓄力时间缩放范围和伤害。子弹行为位于 `projectile.lua`，冲击波规则位于 `arena.lua`。技能树文字 `label` 是独立配置，修改升级增量时应同步更新文字。

战斗会触发攻击、墙壁反弹、敌人命中、敌人死亡、引爆与死亡等音效事件。当前已配置的事件使用运行时合成音；取得明确授权后，也可以在 `audio.lua` 中通过 `path` 配置单文件，或使用 `paths` 轮换多个文件，战斗代码无需调整。

此次抽取集中于游戏调参和资源配置；绘制坐标、粒子动画细节、引擎默认值和算法常量仍在对应实现中。`conf.lua` 保留 LÖVE 引擎启动选项，并从 `display.lua` 读取窗口尺寸。
